Established the project constitution for the task-list application, covering the six
agreed principles: simplicity, accessible interaction, validated input and actionable
errors, safe persistence, behavior-focused tests, and consistency between specifications,
plans, tasks, tests, and code.

Development stage; later artifacts and implementation should stay consistent with it.
